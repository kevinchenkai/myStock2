# ADR 0002：模拟执行协议与记分牌口径（M5）

- 状态：已采纳（2026-10-05，随 M5 落地；**协议版本 `exec-v1`**）。观察期开始后修改＝新协议版本＝新比较批次（方案 §7）。
- 依据：方案 §5 M5 前置「执行协议 ADR」、§6A、§8.2 T-05/T-23/T-31/T-33/T-37/T-41/T-43
- 适用：`human_plan`、`ai`、`ai_veto`、`buyhold` 等**正式模拟线**。`human_actual`（真实成交）原样记账、不撮合，不适用本协议。

## 决定

| 项 | 规则 |
| --- | --- |
| 订单有效期 | 日内单（Day）：目标交易日**开盘前**提交，仅在该交易日常规时段 [open, close] 有效，收盘作废。冻结晚于项目截止的单不进入模拟 |
| 撮合粒度 | **完整的**小时线（`complete=1`）。未走完的 bar 不参与 |
| 限价单成交条件 | 买：bar 的 `low` **严格低于**限价；卖：bar 的 `high` **严格高于**限价。**触价（相等）不算成交**（保守） |
| 成交价 | **一律按限价成交**，不因跳空而享受更优的开盘价（保守：永不优于限价） |
| 成交量上限 | 每个满足条件的 bar 最多成交 `max_participation × bar.volume`（默认 0.10，向下取整到整手），多 bar 累计，剩余量收盘作废；`volume` 缺失则该 bar 不能确定容量 → 视为不可知 |
| 同 bar 双边触达 | 同一线、同一标的的买单与卖单在同一 bar 都满足条件：**不假设「先买后卖」**；卖单只能使用**当日开盘时已有的可卖库存**，当日新买入的股票当日不可卖；该 bar 记 `ambiguous_bar` 标记并计入歧义日 |
| 库存与现金 | 买单提交时按 `qty × 限价 + 最大估算费用` **预留现金**，不足则整单拒绝（`cash_insufficient`）；卖单数量不得超过开盘可卖库存（`insufficient_inventory`）。卖出回款按结算规则（`SettlementRule.lag_sessions`，**必须显式配置，未配置报错**）延后可用，期间计入权益但不可买入。日终释放未用预留 |
| 费用 | 四类线**共用同一份费用档案**（`fees.estimate`，聚合层级按档案）；无适用档案报错，**不默认为 0**；敏感性：费用×2、滑点由 `ExecProtocol` 参数重跑 |
| 估值 | 日终权益 `E = 现金（含未结算回款）+ Σ 持仓 × 未复权收盘价`；缺任一持仓的收盘价 → 该日 `UNKNOWN`，**不记零、不沿用前值** |
| 公司行动 | 拆股按 `corporate_action` 因子在生效日调整持仓数量与单位成本；**股息不在 M5 模拟线中建模**（见下「已知局限」） |
| 缺 bar / 数据不完整 | 以「session 内 bar 是否覆盖 [open, close]（午休除外，间隙 ≤ 1 分钟）」判完整性。不完整时：若订单**已在可得 bar 上全部成交**则成交可知；否则（部分成交/未成交）该日 `UNKNOWN`——因为缺失的 bar 里可能已成交，无法确定库存 |
| `UNKNOWN` 传播 | 该线从该日起 `PAUSED`：不推进状态、不评分；恢复＝用补齐的行情**新证据快照**重新模拟（新 run，旧 run 保留）；**不删日、不假定库存**（方案 §6A.6） |
| 买入持有 | `D0` 后首个交易日，在共同状态冻结之后，以**该日首根完整小时线的开盘价**按预注册权重一次性买入（整手取整，余款留现金，扣同一费用档案），此后**永不交易**；股息不再投资（不建模）。不得倒填成交价 |
| 主指标 | 正式交易仓权益 `E`，`E0=E_trade(t0)`；`r_t=(E_t−E_{t−1})/E0`；`Δ_t=r_AI,t−r_ref,t`；`Σ Δ_t = R_AI(T)−R_ref(T)`（方案 §6A.5）。**只在两条线该日均为 `OK` 的日期上配对**，并报告覆盖率 |
| 统计 | 按时间块的成组重采样（同一日期的全部标的一起，因为 Δ 已是币种袋级别）；滚动区间只作描述，不触发晋级（§6A.7） |

## 已知局限（如实）

1. **价格收益口径，不含股息**。股息数据源（除息日、金额）尚未核实（M0a：富途快照无除息日字段）；买入持有与 AI 线对股息的暴露不同，故二者比较**偏向少持仓者**。核实数据源后新增协议版本（`exec-v2`）补入，不改写 `exec-v1` 的历史结果。
2. 小时线供应商切分口径（美股 09:30 起整点、港股午休前后）未核实；完整性判定用「覆盖 [open, close]」的结构检查，可能把供应商正常的切分误判为缺口（偏保守：宁可 `UNKNOWN`）。
3. `max_participation` 与「严格穿越」是保守假设，**不是对真实成交概率的估计**；敏感性（参与率、费用×2、剔除歧义日）与主表并列。
4. 订单只有限价日内单与买入持有的开盘价市价单两种形态；其余订单类型（止损、IOC 等）不在 `exec-v1`。

## 「ADR 必答」问题回答（方案 §5 M5 前置）

| 问题 | 回答 |
| --- | --- |
| 订单生效时点 | 目标日开盘前提交，常规时段内有效（Day） |
| 跳空穿越限价的成交价 | 限价（不因跳空改善） |
| 单 bar 成交量上限与部分成交 | `max_participation × volume`；多 bar 累计；剩余作废 |
| 库存释放 | 当日新买入当日不可卖；卖出回款按结算规则延后可用 |
| 同 bar 双边触达 | 不假设顺序；卖单只用开盘库存；标 `ambiguous_bar` |
| 缺 bar/停牌/缺行情 | 区分「行情完整的计划失败」（确定，继续评分）与「无法确定」（`UNKNOWN`→暂停）；覆盖率阈值见协议，低于阈值暂停正式推断 |
| 碎股与 tick | 买价向下、卖价向上舍入到合法 tick（`SecurityRule.legal_limit`）；碎股（非整手）订单不成交 |
| 缺失行情后的恢复 | 新证据快照重新模拟，新 run，旧 run 保留 |
