# myStock 项目书

## 核心功能

### 1. Web 交易分析与看板
* **数据接入**：通过 API（Futu、yfinance 等）获取个人实时数据与历史行情信息，搭建专属的个人股票交易分析工具。
* **功能定制与持续迭代**：
  * **我的持仓**：实时仓位分布与资产监控
  * **交易记录**：历史成交与买卖流水管理
  * **盈亏分析**：单笔/累计交易盈亏统计
  * **资产趋势**：净值与总资产历史走势图
  * **外汇监控**：美元/港币汇率换算与跟踪

---

### 2. ML 智能决策与策略辅助
* **交易范围**：针对圈定的优质标的（如：NVDA、TSLA、0700 等），在合理价位（逢低买入 / 逢高卖出）进行**天级别（日线级）**波段交易。
* **大模型建模预测**：
  * 引入前沿大模型能力，结合个人账户资产、持仓与历史成交记录进行独立建模，输出 **T+1 日操作指导**。
* **操作复盘与指导**：
  * 对实际的人类主观操作（买入/卖出）进行回放与归因复盘，提炼交易得失，生成优化建议。
* **核心优化目标**：
  * **收益对标**：驱动 AI 算法策略的实盘/模拟收益持续超越人类直觉交易收益（$\text{AI指导收益} > \text{主观操作收益}$）。
