## 1. 总体结论

**有条件通过。**

三条证据路径、线内状态、账本只追加，以及「确认样本必须等协议冻结之后才开始计时」，方向是对的。§4 把全量历史导入、完整 Web、复盘和 LLM 移出关键路径，也成立：前向日数无法加速，合格证据又不能靠事后补造。

还不能直接通过。作为正式判定唯一权威的 §6A／§6，仍有几处会改写主检验统计量或对照资格：权益用哪一种价格没有写死，股息按「除息日持股数」计提会把权利算错，`buyhold` 在权威契约里没有操作定义，密封范围盖不住目标日预测和生成命令的输出。这些是契约补丁，不必推翻里程碑或 §2.2 的路径划分。

本意见只依据方案正文、原始想法、两份项目书和协作约定，不把文首已有评审结论当作论据。富途限频、结算周期、`yfinance` 小时线保留范围，方案已交给 M0a 核实；下面不把这些写成已核实事实。

## 3. 最危险的 3 个假设

1. **每日都能在看到目标日预测之前记下结构化计划。** 缺失被预注册为「无订单」后，正式检验包含记录纪律和截断规则。漏记几天，人类线就会看起来像空仓。
2. **被评分的 `ai` 线就是用户拿来下单的指导。** `line_sim` 用自己的库存，`live_guidance` 用真实账户，而且不进正式评分。两条线分叉之后，模拟胜负不再回答「我按指导操作是否赚得更多」。
3. **§2.3 的功效量级可以代表这条配对差。** `σ = 1%` 仍是假设；持仓跨日重叠、厚尾，以及 `E0` 里的核心仓，都会让 120 个交易日的首次评审停在「继续观察」。把首次统计显著当成策略晋级，会得到错误结论。

## 4. 被遗漏的最重要的一项

**模拟胜负与真实执行之间没有降级规则。** 原始命题比的是「AI 指导之下的操作」和「主观操作」。方案正确地拒绝把真实成交和模拟成交当成同协议，但没有规定：当 `live_guidance` 与正式 `ai` 线持续给出不同动作，或真实成交系统偏离 `live_guidance` 时，正式结论必须降级为执行诊断，不得保留「指导有效」。没有这条规则，记分牌可以在用户并未执行的那条线上宣布获胜。
