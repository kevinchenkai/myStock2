## 3 与实施方案 v1.1 的偏差与新增决定（真实数据暴露的问题）

1. **成本口径**：富途 `cost_price` 是**摊薄成本**（可为负），`average_cost` 才是平均成本。迁移 0008 新增 `average_cost`/`diluted_cost`；开账成本证据只用平均成本，且要求开账后该标的无成交。旧假设「`cost_price` 是每股成本」作废（浮盈曾被算错）。
2. **开账方式**：除「以快照开账」外新增**倒推开账**（`ledger open --at <t0>`）：期初股数＝快照 − t0 之后全部成交（精确）；期初现金是残差（吸收未入账的出入金/换汇/利息，不是真实期初现金）。富途账户于 2024-10-21 升级（流水 `资产迁移`＝旧账户资金迁入，成交历史也止于此），**开账点定为 2024-10-20**：期初现金≈0（HKD 0、USD −13.85），之后全部现金变动均有流水，现金曲线水平可信；期初持仓是迁入的股票，无成本证据。
3. **V1 日快照**没有采集时刻（`captured_at` 是当日 23:59:59Z 占位）：默认不用于开账/对账，`reconcile` 直接拒绝；只作交叉核对。
4. **股息**：现金分红与预扣税是两条流水，配对为股息组；接口无除息日，应收与到账同日（局限）；美股新旧两种备注格式与港股 `<SEHK n>` 格式均可解析；同日多笔股息各自成组。
5. **账户级费用**（ADR 费、公司行动服务费、过户费、ADR 取消费）无对应成交：记为 `ADJUST(INVESTMENT)`，计入业绩，不是外部流水。
6. **订单费用**接口无币种：核实后按成交市场币种入账（`--assume-market-currency`）；后续入账自动结清先前进入待匹配队列的陈旧项。
7. **行情**：供应商偶发 OHLC 自相矛盾/NaN 行只丢该行（留缺口），不拖垮整个标的；`US.YY` 已更名 JOYY，行情按 JOYY 取。
8. **预测密封**：事后重建（rebuilt）的预测不属于任何前向样本，不密封；前向（forward）预测仍按 §6A.2 密封。
9. **环境**：V2 兼容 Python 3.10（与 V1 共用 `mk`）；属性测试在无 hypothesis 时自动跳过。
10. **表格与外汇**：所有按代码/币种列出的表有「全部/美股/港股」筛选（记在 localStorage）与点击排序（数值列先降序、缺失永远在最后）；外汇页只展示 USD⇄CNY（港币汇率仍在采集，供折算使用）。
11. **操作单页**：AI 操作单依赖比较批次，没有批次时不再整页不可用；页面新增「我的订单」（`broker_order`，V1＋富途）。
12. **翻页与行点击**：所有表格通用翻页（先筛选、再排序、最后切页）；行点击改为随重绘保持正确。
13. **财务统计**：盈亏页新增年度现金流统计（V1 口径，按年/按市场，另列股数、费用、含费用净现金流）。

## 14 后记：例行更新 hk 阶段写前向预测（2026-10-06）

- **改动**：`update --phase hk` 在原有 rebuilt 回补之后，对名单内 HK 标的、最近一个已收盘交易日，各模型（baseline、lgbm）再跑一次 `forecast run --start D --end D --tag forward`。`us`、`pre` 阶段不写前向。
- **不依赖「最后一次」**：hk 阶段每个交易日有 4 个时间点，但第一次「完整成功、且在收盘 1 小时后」的运行之后，其余被增量检查跳过；该次运行即写前向。Mac 当时离线则由下一个时间点补上。若到目标日开盘之后才补跑，时间规则（`forward_generated_after_target_open`）拒绝，该日只留 rebuilt；`forecast run` 对前向的拒绝只打印、不算失败。
- **去重**：`record_prediction` 与 `generate` 对前向增加 `existing_forward`——同标的、同数据截至日、同 `model_version`/`feature_version`/参数的前向只留第一条，重复运行返回已有 id、不再写证据快照。参数不同（如教练协议参数的基线）视为另一条，不互相顶替；rebuilt 不受影响。
- **已知**：教练流程（`coach run`）若与例行更新的基线参数相同，会拿到例行更新先写的那条（输入截止时间略早于教练运行时刻）。
- 测试：`test_forward_is_written_once_per_code_day_model_params_and_late_runs_do_not_duplicate`、`test_hk_phase_also_writes_forward_forecast_for_last_closed_session_only`；全量测试与 ruff 通过。
