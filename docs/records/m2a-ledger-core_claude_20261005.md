## 发现与取舍（如实）

1. 迁移 0002 在首次提交前自行修订过一次（补 `uq_reversal_once` 唯一索引）；此时尚无任何已应用该迁移的数据库，未违反「迁移只前进」。此后修改须新增迁移。
2. 事件校验把时间/金额解析错误统一包装为 `LedgerError`，避免调用方漏接底层异常。
3. `settlement_state` 未建表，改为派生计算（见 ADR）。方案 §6 表清单与此有一处偏差，已记录；M5 如需持久化再加。
4. 结算周期（美 T+1/港 T+2 等）**没有写入任何默认值**：未配置即报错，等 M0a 核实。
