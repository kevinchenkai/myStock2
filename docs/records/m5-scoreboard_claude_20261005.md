## 偏差与说明（如实）

1. **股息不在 exec-v1 中建模**（ADR 局限 1）：股息数据源（除息日、金额）尚未核实；买入持有与 AI 线因此**偏向少持仓者**的比较要如实标注。核实后新增协议版本，不改写 exec-v1 历史结果。
2. 引擎不含 `receivable` 项：`E0=E_trade(t0)` 中的期初应收应付由调用方并入初始状态的现金/文字说明——**当前 `LineState` 没有应收字段**，含期初应收的开账需在 M6 冻结批次时处理（T-33 的 `E0=2100` 反例仅验证了指标公式，未经引擎）。
3. 小时线「完整性」`session_complete` 由 `MarketData` 实现方判定；真实 `DbMarketData`（基于 `market.bars`）**尚未实现**，将在 M6 把 coach/ticket 接上时一并落地。
4. `strategy_line.params_hash`、`line_state` 的使用方式留待 M6 与 ticket 的 `state_ref` 对接；`eval_run.metrics_json` 在建 run 后更新一次（触发器未禁止对 `eval_run` 的 UPDATE，只禁止 DELETE），属于已知宽松点。
5. 参与率 10%、严格穿越、按限价成交是**保守假设，不是对真实成交的估计**。
