## 口径与取舍（如实）

1. **预测只读 `source_tag='rebuilt'`**，每个模型取 as_of 最大的一条，标「事后重建、非前向证据」。前向（forward）预测的数值**根本不读取**，只用「同一目标日是否存在前向预测」这个布尔信息：若存在、目标日尚无终值日线且无揭示记录，该行只显示「已密封」、不含价位（与 M3c「rebuilt 不密封、有前向则仍密封」的处置一致）。视图里没有任何 ticket/AI 操作单字段，测试用哨兵值断言（密封与已揭示两种库）。
2. **日涨跌**取最近一个 ok 收盘与「日历上的前一交易日」的 ok 收盘之差；前一交易日缺行情，或两日之间有拆股（未复权价不可比）→「不可用」，不拿更早的日子冒充。
3. **52 周高低**自算值是未复权日线最高/最低价（不足 250 个交易日会标明实际天数）；与档案来源值并列、互不覆盖，遇拆股两者会不同。
4. **股息/预扣税**：来自账本 `DIVIDEND_PAYMENT`，预扣税按同一支付组（`group_id`）归属 `TAX`；只知净额的股息，差额（`DIVIDEND_SHORTFALL`）单列为「性质未知」，不记为税；开账日及以前的记录只作描述、不计入；没有记录显示「无记录」而不是 0。
5. **订单**是意图，页面写明；不进入持仓与盈亏（测试：新增一条巨额订单，持仓/成交/走势块逐项不变）。状态映射表之外的状态原样显示；价格 0（市价单）显示「不可用」。订单按代码取全部账户（含 V1 来源），列出来源。
6. **资金流向**净流入为正标红、为负标绿；不同来源分行、不相加；合计只含有数据的日子并标出有数据的天数；最新记录日早于应有收盘日则标陈旧。
7. **新鲜度头部**只含行情与账本两个来源；订单/资金流/档案/预测各块自带 as_of/来源/陈旧提示（档案与重建预测的小时级陈旧阈值没有意义，未纳入头部，否则头部几乎恒为「陈旧」）。
8. **名称只作展示**，来源与优先级沿用 `instrument_name`（迁移 0009）；`stock` 抬头直接读该表。
9. 窄屏表格沿用卡片折叠；弹窗里的表格关闭了市场筛选（单一标的无意义）。
