## 做了什么

- `forecast/lgbm_cqr.py`：借用 V1 的 16 个特征（只用 ≤T 的信息）、重写；LightGBM 原生 API 分位回归（低 α=0.10、高 α=0.90）＋**单侧 CQR** 校准（训练｜隔离｜校准按时间切分，有限样本修正的分位水平）；固定 seed、单线程、deterministic。
  - 修复 V1 两处问题：标签统一用**复权**口径（V1 用原始价，拆股日会错）；缺 LightGBM **明确失败，不静默回退 sklearn**。
  - 输入不足/缺复权价/特征含缺失/区间倒挂 → `ForecastUnavailable`，不外推。
- `forecast/evaluate.py`：时间有序滚动评估（pinball、覆盖率），晋级门槛函数（沿用 V1：等权改善 ≥5% 且至少 ⌈2n/3⌉ 个标的改善），只回答「预测更准吗」，不回答「更赚钱吗」。
- `forecast/run.py generate(model="lgbm")` 与版本留档支持按 `model_version/feature_version` 记录（`lgbm-cqr-v1` / `f-v1-16`）。
- 新增依赖 `lightgbm`（原生 API）。

## 探索性评估（公开历史行情；**开发期证据，不是前向证据**）

脚本 `scripts/explore_lgbm_vs_baseline.py`：用 yfinance 拉取 V1 的 6 个标的（US.NVDA/TSLA/PDD、HK.00700/09988/01810）自 2020-06 起的日线，对最近约 400 个交易日每隔 5 个交易日做一次「截至 t 预测 t+1」（每标的 80 个起点），比较**基线**与 **LightGBM+CQR**（`n_rounds=100`，其余默认）。

| 标的 | 基线 pinball（低+高） | LGBM+CQR | 相对改善 |
| --- | --- | --- | --- |
| US.NVDA | 0.00825 | 0.00751 | **+9.0%** |
| US.TSLA | 0.01040 | 0.01042 | −0.2% |
| US.PDD | 0.00777 | 0.00867 | **−11.6%** |
| HK.00700 | 0.00611 | 0.00575 | **+5.8%** |
| HK.09988 | 0.00945 | 0.01006 | −6.4% |
| HK.01810 | 0.00853 | 0.00794 | **+6.9%** |

- **门槛判定**：等权平均改善 **+0.57%**（< 5%），3/6 个标的改善（需要 ≥4）→ **不通过**。
- 覆盖率（目标 10%）：基线与 LGBM 的低/高侧覆盖率都在大约 3%–15% 之间波动，80 个样本下的随机波动很大，不能据此说谁校准更好。

**解读与局限（如实）**：
1. 这是一次探索性比较：**单次运行、单一参数设定、每标的仅 80 个起点**；评估窗口（最近约 400 个交易日）此前未被反复使用，但这一次之后即成为「开发窗口」，不得再称「全新留出集」。
2. 没有对 LightGBM 参数或基线参数做任何事后调整以改善结果（调参属于搜索预算，须登记）。
3. 结论是**不晋级**：按方案，预测层晋级与策略收益分别验收，未过预测门槛前不以 `ai_lgbm` 线进入前向观察；这是一次负结果，如实记录（与 V1 的模型矩阵「无候选过门槛」一致）。
4. 若要继续：登记假设与搜索预算后再做（例如更长历史、更多起点、合并池化训练、调整特征），每次只改一个因素；同时分开评估区间宽度（决定边际门槛 `no_edge`）与价位本身的价值。
