## 首跑发现并修复的问题

1. **富途 `cost_price` 是摊薄成本（可为负），`average_cost` 才是平均成本**：原假设「每股成本」错误，已新增迁移 0008（`average_cost`/`diluted_cost`），开账成本证据只用平均成本，且要求开账后该标的无成交；持仓页并列显示两者。
2. 供应商偶发 OHLC 自相矛盾的行会让整个标的采集中断 → 只丢该行（留作缺口）。
3. V1 日快照被 `ledger open/reconcile` 默认选中 → 默认排除，`reconcile` 拒绝（占位时刻会把盘中成交变成假差异）。
4. 现金分红与非美国居民预扣税是两条流水 → 配对成一笔股息（接口无除息日，应收与到账同日）。
5. 订单费用无币种 → `--assume-market-currency`；后续入账会自动结清先前进入待匹配队列的陈旧项。
6. 与 V1 同环境：V2 兼容 Python 3.10。
