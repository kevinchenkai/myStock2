## 2 设计方向（建议）

气质：**诚实、克制、金融工具**——像券商终端的「对账单」而不是营销仪表盘。不加装饰图，不加渐变，不引入外部字体。

| 维度 | 方向 |
| --- | --- |
| 色板与 token | `app.css` 全面 token 化：中性灰阶（背景/表面/边框/文字 4 级）、强调色（冷蓝，只用于交互与选中）、语义色（涨＝红、跌＝绿、汇率＝中性蓝灰、警告＝琥珀、信息＝蓝、未知＝灰）；深/浅两套重新校准，正文与数字对比度 ≥ 4.5:1，涨跌色在两种背景上都 ≥ 4.5:1；红涨绿跌、汇率中性的规则与现有测试保持 |
| 排版层级 | 系统字体栈不变（PingFang/苹方等）；页标题 20px/600，卡片标题 15px/600，KPI 数值 22px/600 等宽数字，正文 14px，辅助 12px；所有数字 `font-variant-numeric: tabular-nums` |
| 间距 | 4px 基准（4/8/12/16/24）；卡片内边距 16px，卡片间距 12px；宽屏内容最大宽度 1240px |
| 导航与页头 | 顶栏吸顶：品牌＋导航＋主题按钮；导航按「账户 / 教练 / 系统」三组，宽屏为下划线式标签，窄屏为**单行横向滚动**（不折行）；每页有页头：标题＋一句话说明＋**新鲜度徽标**（新鲜/陈旧/未知＋相对时间），完整的数据模式/事件时间/采集时间/来源列表收进可展开的「数据来源」 |
| 参数栏 | 用中文短标签（来自 view.yaml 的 description 第一段），控件统一高度与样式，放在页头右侧/下方的工具区 |
| KPI 摘要卡 | 统一「标签（小）＋数值（大）＋副行（币种/口径标签）」的 stat tile；在总览、持仓、盈亏、资产趋势、数据状态等页把最关键的 3–6 个数字放在最上面 |
| 表格 | 紧凑密度（行高约 36px）、斑马纹＋行悬停、**粘性表头**、数字列等宽右对齐；买卖/状态用小号徽标（买＝蓝、卖＝琥珀，**不用红绿**——红绿只表示涨跌）；工具条（市场分段、列筛选、排序、行数）与翻页条统一为同一套小号控件 |
| 窄屏表格 | 见「待你决定 U1」 |
| 图表 | 继续自绘 SVG（不引入图表库）：首绘前等待容器有宽度（`ResizeObserver`，并在移除时解绑）；固定像素字号（不随 viewBox 缩放）；4–6 个「整齐」的 y 轴刻度与 4–6 个日期刻度；悬停时竖线＋各曲线圆点＋**浮动读数框**（窄屏贴底）；主曲线下方淡色面积；买卖标记（▲ 买 / ▼ 卖，颜色不用红绿）保持并在读数里列出；缺口灰带；资产趋势的「收益」曲线单独成图（不再和权益共轴） |
| 状态 | 加载态：骨架条；空态（「还没有比较批次」等正常的无数据）：中性灰框＋一句话＋下一步怎么做；不可用（缺数据）：中性灰；错误：琥珀/红框；三者不再共用一种琥珀色 |
| 弹窗 | 股票详情：页头显示代码＋中文名＋最新价与涨跌（服务端单元格）；新鲜度收进可展开区；窄屏全屏、页头吸顶 |
| 可访问性 | 焦点环、键盘可达（已有）保持；色彩之外用文字/符号区分（▲▼、徽标文字） |

## 3 决定

| 编号 | 取舍 | 选项 | 我的建议 |
| --- | --- | --- | --- |
| U1 | **负责人选 A（2026-10-05）**。窄屏（375px）表格怎么呈现 | A **两列紧凑卡片**：每行一张卡，首字段（标的/日期）做卡片标题，其余字段两列网格（标签在上、值在下），高度约为现在的 1/2–1/3；B 保留表格，横向滚动，首列吸附；C 每张表在 panel 里声明 3–4 个「窄屏主列」，其余字段收进点开的详情 | A：通用、所有表一次到位、不需逐表配置；B 在 375px 上要横向拖动，金额多时难读；C 最好看但要逐表配置、且改动 12 个面板 |
| U2 | **本次未改，维持 UTC**。页面时间显示时区 | A 维持 UTC（现状，与存储一致）；B 显示本机时区（PDT，标注 PT）；C 成交类按交易所本地时间（港股 HKT、美股 ET），系统时间用 UTC | 目前全页 UTC。B 最符合你的阅读习惯，但港股成交会显示成前一天深夜；C 最符合交易语义但同一页有两种时区。**建议先维持 A**（本次不改口径），留作后续 |
| U3 | **负责人选 A（2026-10-05）**。导航分组 | A 三组（账户：总览/持仓/流水/盈亏/趋势/外汇；教练：操作单/记分牌/预测/复盘；系统：数据状态）；B 维持平铺 11 项 | A |

### 4.3 检查

- 截图：合成演示库，12 页 × 桌面 1280 / 窄屏 375 × 浅 / 深，改前改后各一套（只在本机临时目录）。改后两种主题、两种宽度均无横向溢出、无控制台错误。
- 375px 页面高度（CSS px，改前 → 改后）：交易流水 16,396 → 6,525；操作单 15,417 → 6,826；复盘 35,206 → 15,788；盈亏 13,426 → 9,008；预测效果 6,877 → 6,487；其余页面变化在 ±15% 以内（新增摘要卡使总览、资产趋势、外汇略高）。
- 对比度：正文、辅助文字、「不可用」、涨/跌色、强调色在两种主题背景上均 ≥ 4.5:1（`tests/unit/test_web_frontend.py` 参数化测试）。
- 三件套：每个提交都跑 `pytest`、`ruff`、`check_docs`、`git diff --check`，全部通过（`mk` 环境无 hypothesis，属性测试跳过 1 个，负责人决定不装）。
- 外部资源：无外部字体/CDN/图片；无内联脚本/样式（原有测试覆盖）。
